# Embedded basemap data

`ne_110m_admin_0_countries.geojson` is the Natural Earth 1:110m Admin 0 Countries
layer. Natural Earth data is in the public domain:
https://www.naturalearthdata.com/about/terms-of-use/

Source repository:
https://github.com/nvkelso/natural-earth-vector

The file is embedded at compile time. No tile server, account, or runtime
network request is used for the map.
