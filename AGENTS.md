# AGENTS.md

This is safety-critical storm chasing software. People stand in open fields with tornadoes bearing down on them, making life-or-death decisions based on what this display shows. A misplaced bin puts a storm in the wrong location. A silently swallowed error shows stale data as current. A frozen screen looks like clear skies when a wedge tornado is two miles away.

[ROADMAP.md](ROADMAP.md) owns product behavior, architecture, safety, and milestones. [STYLE.md](STYLE.md) owns code and prose style, including lint and test conventions. Both bind every change.

Every rule here is absolute.

No banned code pattern receives an exception. A banned pattern that appears required means the ownership or data model is wrong. Restructure the code.

## Gates

Both must pass before any milestone is considered complete. There are no partial completions.

```
cargo clippy -- -D warnings
cargo test
```

The lint set is the `[lints]` table in `Cargo.toml` and the thresholds in `clippy.toml`. `#[allow]` is not available.

The gates are necessary, not sufficient. A milestone is complete only when its acceptance criteria in [ROADMAP.md](ROADMAP.md) are observed in the running binary and its interaction budgets are measured. A green gate over an unusable display is a failed milestone.

## Unconditional Bans

No argument makes these acceptable. No permission is available for any of them.

**Panicking:** `unwrap()`, `expect()`, `panic!()`, `unreachable!()`, `todo!()`, `unimplemented!()`, `assert!(false, …)`, `debug_assert!()`, and indexing or slicing on a computed index without a proven bound.

**Unsafe:** `unsafe { }`, `unsafe fn`, `unsafe trait`, `unsafe impl`.

**Silent error discard:** `let _ = fallible()`, `.ok()` without explicit handling, `.unwrap_or_default()`, `map_err(|e| e.to_string())`.

**Other:** `#[allow(…)]`, `#![allow(…)]`, commented-out code of any kind.

If the compiler requires handling a branch you believe is unreachable, handle it gracefully: return an error, surface a message to the user. You may never assert that a branch is unreachable.

## Commit Messages

Commit messages contain the technical change and its reason. Trailers are prohibited: `Co-Authored-By`, `Signed-off-by`, `Generated by`, and harness-specific footers. No AI, model, or tool attribution appears in the log.

## Ownership and Concurrency

`Arc`, `Rc`, `RefCell`, `Mutex`, `RwLock`, `Cell`, `OnceCell`, `LazyLock`: banned.

Ownership resolution order: `&T` → `&mut T` → move `T`. `clone()` to satisfy the borrow checker means the ownership model is wrong. Fix the model.

**Approved concurrency pattern:** worker thread owns its data exclusively → produces a completed owned value → sends it via `std::sync::mpsc` → UI thread owns all display state exclusively and never shares it. No other cross-thread pattern is used.

## Error Handling

- Every fallible call must be handled: `?`, `match`, or typed conversion. Discarding a `Result` in any form is forbidden.
- Failures use typed enums whose variants carry the invalid value. `Display` and `Error` are written by hand so every message reads as a sentence for the user.
- Preserve the underlying cause with `source()`. Never `Box<dyn Error>`, never `map_err(|e| e.to_string())`.
- Every error must appear in the UI as a human-readable message. Errors written only to stderr or logs are invisible to the user, and an invisible error is a silent failure.
- Error messages use sentence case: `"Failed to fetch radar data for site {site}: {source}"`.

## Structure

Edition 2024. One module per logical concern, named files (`radar.rs`, `tiles.rs`), no `mod.rs`. `main.rs` holds argument parsing and app construction. No unlisted dependency without asking. Implement only the current milestone: no stubs, no scaffolding ahead.

## Radar Data Integrity

No hardcoded geophysical constants in rendering paths. Gate geometry, azimuth spacing, site coordinates, and elevation angle are read from the data for every radial. If the data does not supply a valid value, the bin or radial is rejected and its count is surfaced in the UI. It is never substituted with a default. A bin placed one gate off puts a storm in the wrong location. A storm in the wrong location kills someone who turned the wrong way.

## Coordinate Mathematics

Formulas and reference values are in `ROADMAP.md`. Implement them exactly as specified. The Reference Values tables are the source of truth for absolute-value tests, with the stated tolerances. Earth constants are named in the roadmap and are not interchangeable.
